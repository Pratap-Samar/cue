# CUE

CUE is a minimal Bash-based Linux reminder and recurring notification utility.

## Status

Early development — Phase 1: project foundation.

## Planned Features

- One-time reminders
- Recurring reminders
- Persistent reminder state
- Linux desktop notifications
- Cron-based scheduling
- Reminder history
- CLI-based management

## Planned Stack

- Bash
- Linux
- Cron
- notify-send
- Bats
- ShellCheck
- GitHub Actions
